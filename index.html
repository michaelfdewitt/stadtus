Stadtus

Every object in your data is a building. The hierarchy decides where it stands; three fields decide how tall it is, its color, and the length of the spire on its roof. The city never moves when you filter, so you can learn your way around it.

MoveWASD fly · Q/E down/up · hold Shift for speed
Lookdrag to orbit · right-drag to pan · wheel zooms toward the cursor
Selectclick a building · shift-click adds · click a district plate to select its contents
Zoom todouble-click a building or district · breadcrumb to go back up
Filterclick legend values to hide/show · shift-click shows only that value · drag the histogram sliders
TriageJ/K next / previous building by height · 1–9 fire the numbered actions
Timepick a Time field in Encoding; drag the scrubber or press Space to play. Buildings appear as their date passes
Sharethe URL always holds the current view: encoding, filters, focus, time, selection, camera. Copy it to send a finding
KeysR reset view · F fly to selection · Esc clear filters and selection · P save PNG

Load a JSON file: either { "name", "items": [ { "name", "path": ["a","b"], ...fields } ] } or a plain array of objects (you'll be asked which keys form the hierarchy). Field types are inferred. Nothing is uploaded anywhere.
